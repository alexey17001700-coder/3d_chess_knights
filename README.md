# 3D Шахматы — Рыцарский турнир

Трёхмерные шахматы в стиле NEXUS SPACE: тёмный зал, звёздное небо, светящаяся кромка доски,
фигуры в средневеково-рыцарском стиле (ладья-башня, слон с настоящей прорезью в митре,
конь с вырезанной из силуэта головой и гривой, корона у ферзя и короля).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | страница, HUD, окно настроек графики |
| `style.css` | оформление HUD (тёмное стекло + неон) |
| `pieces.js` | процедурная геометрия фигур (без внешних моделей) |
| `scene.js` | сцена, свет, доска, камера, качество графики, FPS |

## Графика

Пять режимов: **АВТО**, НИЗКОЕ, СРЕДНЕЕ, ВЫСОКОЕ, УЛЬТРА.
Плюс отдельные переключатели: тени, отражения, звёзды, сглаживание, авто-разрешение.

* **АВТО** — уровень подбирается по ядрам, памяти и типу устройства.
* **Авто-разрешение** — если FPS падает ниже 42, разрешение снижается; если выше 57 — возвращается.
* Выбор сохраняется в `localStorage`.

## Статус

* ЭТАП 1 — сцена, доска, фигуры, свет, камера, настройки графики. **готово**
* ЭТАП 2 — игровая логика (полные правила), выбор фигуры, ходы, подсветка.
* ЭТАП 3 — анимации хода, звук, PWA-обновление.

## Технологии

Three.js 0.160 (ESM через importmap), PBR-материалы, `RoomEnvironment` для отражений,
PCFSoft-тени, ACES-тонмаппинг.
