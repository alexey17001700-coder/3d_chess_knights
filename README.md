# 3D Шахматы — Рыцарский турнир

Трёхмерные шахматы в стиле NEXUS SPACE: тёмный зал, звёздное небо, светящаяся кромка доски,
фигуры в средневеково-рыцарском стиле (ладья-башня, слон с настоящей прорезью в митре,
конь с вырезанной из силуэта головой и гривой, корона у ферзя и короля).

**Играть:** https://alexey17001700-coder.github.io/3d_chess_knights/

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | страница, HUD, окна настроек графики и партии |
| `style.css` | оформление HUD (тёмное стекло + неон) |
| `pieces.js` | процедурная геометрия фигур (без внешних моделей) |
| `scene.js` | сцена, свет, доска, камера, качество графики, FPS |
| `chess.js` | движок правил (чистая логика, без графики) |
| `game.js` | выбор фигуры, подсветка, анимации, HUD партии, ИИ |
| `ai.js` | соперник: негамакс + альфа-бета, таблицы полей, три уровня |
| `ai_worker.js` | воркер — ИИ считает в отдельном потоке, сцена не подвисает |
| `sound.js` | звук через WebAudio-синтез (никаких mp3) |

## Графика

Пять режимов: **АВТО**, НИЗКОЕ, СРЕДНЕЕ, ВЫСОКОЕ, УЛЬТРА.
Плюс отдельные переключатели: тени, отражения, звёзды, сглаживание, авто-разрешение.

* **АВТО** — уровень подбирается по ядрам, памяти и типу устройства.
* **Авто-разрешение** — если FPS падает ниже 42, разрешение снижается; если выше 57 — возвращается.
* Выбор сохраняется в `localStorage`.

## Партия (кнопка ♟)

* **Соперник** — два игрока на одном экране или против ИИ.
* **Играю за** — белые или чёрные (камера разворачивается на свою сторону).
* **Сила ИИ** — ЛЕГКИЙ (глубина 1, ошибается), СРЕДНИЙ (глубина 3), СЛОЖНЫЙ (глубина 5, до 1.9 с).
* **Звук** — синтез: ход, взятие, рокировка, превращение, шах, победа, поражение, ничья.
* **Подсветка ходов** — можно выключить, если мешает.

## Правила

Полный набор: все ходы фигур, взятие на проходе, рокировка с проверкой битых полей,
превращение пешки с выбором фигуры, шах, мат, пат, правило 50 ходов, недостаточный материал,
нотация SAN с `x`, `+`, `#`, `O-O`, `=Q`.

## Статус

* ЭТАП 1 — сцена, доска, фигуры, свет, камера, настройки графики. **готово**
* ЭТАП 2 — движок правил, выбор фигуры, подсветка, анимации, история, отмена. **готово**
* ЭТАП 3 — соперник-ИИ, звук, выбор стороны, полировка под телефон. **готово**

## Технологии

Three.js 0.160 (ESM через importmap), PBR-материалы, `RoomEnvironment` для отражений,
PCFSoft-тени, ACES-тонмаппинг, Web Worker для ИИ, WebAudio для звука.
